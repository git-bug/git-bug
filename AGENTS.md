# Agent Command Execution Directive
- The project uses jujutsu as its version control system.

**Action:** For the following Jujutsu subcommands, you must always
insert the `--no-pager` flag immediately after `jj`:

* `jj log`
* `jj diff`
* `jj show`
* `jj bookmark list` (when listing all branches)
* `jj config` (specifically `jj config list`)
