## git-bug board add-bug

Add a bug to a board

```
git-bug board add-bug [BOARD_ID] [BUG_ID] [flags]
```

### Options

```
  -c, --column string   The column to add to. Either a column Id or prefix, or the column number starting from 1. (default "1")
  -h, --help            help for add-bug
```
